# Architecture Diagrams

These are source-controlled Mermaid diagrams for Aletheia. They are intended to render in GitHub Markdown and stay aligned with the real system architecture.

The public snapshot architecture is intentionally different from the local live architecture. The public demo uses real exported outputs, not a hosted live retrieval backend.

The final README will reference selected diagrams later.
