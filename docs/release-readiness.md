# Release Readiness Checklist

This checklist is for the final repository hygiene pass before resume bullets, interview packaging, and any future release tagging.

## Public Demo

- [ ] Public URL opens: https://aletheia.yuvrajkashyap.com
- [ ] Public demo is configured with `NEXT_PUBLIC_DEMO_MODE=snapshot`.
- [ ] Snapshot data comes from real exports generated by the full local Aletheia pipeline.
- [ ] Admin and live write actions are disabled publicly.
- [ ] The demo does not contain fake data, fake traces, fake metrics, or fake health states.
- [ ] The public site does not claim to run live arbitrary retrieval.

## GitHub Repository

- [ ] `README.md` exists and renders on GitHub.
- [ ] README screenshots render from `docs/assets/screenshots/`.
- [ ] `docs/docs-index.md` exists and links the main technical docs.
- [ ] Architecture, retrieval, evaluation, tradeoff, and benchmark docs exist.
- [ ] Mermaid diagrams exist under `docs/diagrams/`.
- [ ] GitHub Actions CI workflow is present.
- [ ] Local scripts are documented in `docs/dev-commands.md`.

## Local Full Stack

- [ ] Docker Compose can start Postgres, Redis, OpenSearch, and Qdrant.
- [ ] FastAPI can run locally.
- [ ] RQ worker can run locally.
- [ ] Next.js web app can run locally.
- [ ] OpenSearch and Qdrant indexes exist locally after full setup.
- [ ] Local model cache may be needed for dense retrieval and reranking.

## Evaluation And Benchmark

- [ ] SciFact corpus, queries, and qrels are real.
- [ ] Final benchmark table exists in README.
- [ ] `hybrid_rerank` benchmark is labeled sampled.
- [ ] Golden smoke tooling exists for local qrels-backed regression checks.
- [ ] No fake metrics are documented.
- [ ] Generated benchmark and smoke JSON reports are ignored unless intentionally selected later.

## Security And Secrets

- [ ] No `.env.local` file is committed.
- [ ] No connection strings are committed.
- [ ] No real passwords, tokens, or API keys are committed.
- [ ] No model cache is committed.
- [ ] No `node_modules`, `.next`, or virtualenv directory is committed.
- [ ] Production admin key is not documented as a usable default secret.

## Resume And Interview Readiness

- [ ] README is complete.
- [ ] Screenshots are committed.
- [ ] Demo walkthrough exists.
- [ ] Recording guide exists.
- [ ] Interview notes exist.
- [ ] Next steps are resume bullets and interview package, not more product scope.

## Final Manual Checks

- [ ] Public demo link opens.
- [ ] Latest GitHub Actions run is green.
- [ ] README renders on GitHub.
- [ ] Screenshots load in GitHub Markdown.
- [ ] Major docs links work.
- [ ] Latest Vercel deploy is healthy.
- [ ] No broken image links are visible.
