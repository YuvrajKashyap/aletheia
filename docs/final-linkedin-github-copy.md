Aletheia is a full-stack search infrastructure project built with FastAPI, Next.js, PostgreSQL, Redis/RQ, OpenSearch, and Qdrant. It compares BM25, dense vector retrieval, hybrid Reciprocal Rank Fusion, and cross-encoder reranking over BEIR SciFact, then exposes trace-level candidate provenance, document-level qrels evaluation, benchmark reports, experiment comparison, replay workflows, index metadata, and system health. The public demo is snapshot-backed with real exported outputs, while the full live stack runs locally.
